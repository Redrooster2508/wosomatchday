# Session log 2026-11-06

How the project was built, request by request. Commits are in [[Changelog]].

## 1. "Build a women's football match day statistics and analytics" with team photos and matchup probabilities
- Built a prototype page on claude.ai with a **fictional** league ([[Decisions]]) and drawn squad photos.

## 2. "Real time … for Liga F, NWSL and WSL" / "any api?"
- Found **ESPN's public API** with live scores, stats, odds, tables and news, which allows requests from other websites. See [[Data sources (ESPN)]].
- Noted the limits: unofficial, no xG.

## 3. "Can neural networks be used to calculate odds?" → "don't want neural network"
- Explained the trade-offs; none used. See [[Probability model]].

## 4. "Host on git (for now)"
- Built the static site and pushed it to `Redrooster2508/wosomatchday`; the user turned on Pages. See [[Deployment]].

## 5. "Upload photo of team"
- Added shared photos through `photos/manifest.json`, which every visitor sees.

## 6. "Include Champions League" / "source team photos download and upload" / "add matchday table bracket"
- Champions League tab; NWSL bracket with title chances; Champions League projection. See [[Bracket]].
- Explained that crediting doesn't make a photo free to use, then sourced **Commons** photos: 26 kept and 21 rejected after review. See [[Photos and licensing]].

## 7. "Fix this formatting" (empty timeline wrapping one word per line)
- Fixed.

## 8. Fixture card overflow (two reports, the second: "has the fix my ass")
- The first fix was reported as live **without seeing it rendered**, which was a mistake.
- Installed headless Chrome. The pushed code rendered correctly, so the user's browser had a **cached stylesheet** (Pages caches for 10 minutes). Added version tags, and cards now clip anything that doesn't fit.
- The full check also found and fixed: misaligned table rows, a misplaced projection note, a misleading NWSL bracket fallback, a cluttered timeline, and "1 pts". See [[Testing]].

## 9. "Find better photos"
- Built a shortlist with `photo_candidates.py`, scored for team photos and recent years. Reviewing by eye instead of picking automatically.

## 10. "Add a news section" / "add player stats" / "find photos beyond Commons but credit photographer or site"
- News from ESPN.
- Player stats: line-ups with per-player numbers.
- Openverse (Flickr and other Creative Commons sites) added to the shortlist, crediting creator, licence and site. Non-commercial licences allowed.

## 11. "Create/source database for individual players stats"
- `tools/build_players.py`, which only reads new matches: 1,395 player rows across 4 competitions and 395 matches. See [[Player stats database]].
- The scheduled workflow was refused because the token lacks the `workflow` scope.

## 12. "Individual page for players stats, with individual player image"
- `player.html` with a Wikidata/Commons portrait (ESPN has no women's headshots) or initials, plus profile, percentiles, a chart and the match log.
- Fixed in a real browser: Chrome sized table logos as 0px wide, so text overlapped the next column.

## 13. "Update readme, create an obsidian vault and log changes made"
- README rewritten; this vault and the [[Changelog]] created.

## 14. "Possible to do heatmap?"
- Yes: ESPN play-by-play has coordinates on almost every event. Built match-centre heatmaps and shot maps, plus season heatmaps on player pages. See [[Heatmaps]].
- Caught in the browser: goal kicks counted as goals, and an id clash with the score grid.

## 15. "This image is too outdated, check all photos and make sure they are from recent years"
- Checked the capture date of all 26 team photos: only 9 were from 2023 or later. Removed the other 17.
- The photo tools now require 2023 or later and search with "2024", "2025" and "2026". See [[Photos and licensing]].

## 16. "Update and push"
- Pushed the WSL heatmaps. Liga F has no coordinates in ESPN's play-by-play, so the site now says so.

## 17. Victoria Pelova's heatmap blank in Firefox
- Installed Firefox for testing. It drew there, so the user's blank map was most likely Firefox's fingerprinting protection. Switched the heat layer to SVG and tested in Chrome, Firefox, and Firefox with protection on.

## 18. "All the times for the matches is respective to the time of the laptop right"
- Yes: kick-off times are converted to the browser's time zone. Added a note naming that time zone.

## 19. "Photo for individual player is outdated too in some" / "headshots from squad photos"
- Player portraits now follow the 2023+ rule too, with the year in the credit.
- Explained that official squad headshots are copyrighted; free Commons crops are used when they exist.

## 20. "Add metric and imperial measurements"
- Height and weight shown both ways, e.g. 1.80 m (5 ft 11 in), 78 kg (172 lb).

## 21. "Heatmap still with issue"
- The live site already had the fix (verified in Firefox with fingerprinting protection on), but the user's Firefox showed a page cached before it went live. Asked for Ctrl+Shift+R, and added a self-refresh so pages update themselves after a release.

## 22. "Able to get Liga F heatmap from elsewhere then"
- No free source we're allowed to use: Opta/Stats Perform need a licence; SofaScore and FotMob have no public API and forbid scraping; StatsBomb open data doesn't cover current Liga F. Could wire in a licensed feed.

## 23. "Do national teams next"
- Found ESPN's codes from its competition list. Built the National teams tab. See [[National teams]].
- Caught in the browser: overlapping round dates put matches in the wrong bracket columns (fixed with round tags), and broken crest images.

## 24. "Do a predicted winner for each league"
- Built the season forecast. The first version was overconfident (Barcelona 99.96%), so the easing and strength spread were added. See [[Season forecast]].

## 25. ".github/workflows/players.yml, how to add this" → "done A"
- Gave the steps for GitHub's web editor. The user added it, and its first run succeeded.
- Spotted that the run rewrote every file just to refresh timestamps; the builders now leave unchanged files alone.

## 26. Recent team photos (from request 15)
- Reviewed 200 candidates from 2023 on by eye: 24 picked, many rejected (Pride parade, basketball, sailing, cricket, a 1909 photo, a musician). 29 clubs now have recent photos.

## 27. "beyond wikicommon?" → "api only for premium" → "smt like this can it be done" (a Getty credit line)
- Openverse (Flickr) had almost no recent photos of these clubs; Flickr's API needs a paid Pro account.
- A Getty credit line doesn't give us a licence. Getty's free **embed** for non-commercial sites still works (its oEmbed service returns signed embed codes), but its script server blocks this machine, so a test page went live for the user to check in a real browser.
- Found that Commons club **sub-folders** hold hundreds of recent files (Arsenal 468, Man City 308), so the photo search now follows them.

## 28. "Do this too": goal mouth, pass maps, minutes / per-90, team pages, head to head
- All five built. `heat.json` rebuilt with passes, goal-line spots and minutes; team pages and head to head added. See [[Team pages]] and [[Heatmaps]].
- Caught in the browser: team fixtures missing (ESPN needs `fixture=true`), head to head counting the current match, and corners or out-of-play passes inflating progressive passes.
